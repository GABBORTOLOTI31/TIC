
# Projeto Ordem de Serviço

Projeto Java orientado a objetos baseado no diagrama UML enviado.

## Tecnologias
- Java 17
- Maven
- IntelliJ IDEA

## Como executar
1. Abra o projeto no IntelliJ
2. Aguarde o Maven carregar
3. Execute a classe Main.java

## Conceitos aplicados
- Herança
- Polimorfismo
- Classe abstrata
- Interface
- Composição
- Agregação
- Encapsulamento
